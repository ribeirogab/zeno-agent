# Unify DB Stack as Drizzle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the runtime DB layer from `@zeno/storage` (raw `better-sqlite3`, 14 class-repos) to `@zeno/db/runtime` (drizzle ORM), in a single big-bang PR, eliminating the dual SQL convention while preserving the public class-repo API for the ~83 callers.

**Architecture:** Add a `runtime/` subpath under the existing `@zeno/db` package, mirroring the existing `host/` subpath layout. Reuse `packages/db/src/shared/{client,migrate}.ts` (which already provide `openSqlite` + `applyMigrations`/`loadMigrations` against a `schema_migrations` table) — drizzle-kit produces the SQL files, the existing shared runner applies them. The 14 class-repos are ported method-for-method with identical signatures so call sites only swap import paths. `@zeno/storage` is deleted in the final task.

**Tech Stack:** TypeScript strict, Node 24 LTS, pnpm + Turborepo, drizzle-orm `^0.45.2`, drizzle-kit `^0.31.10`, better-sqlite3 `^12.9.0` (kept as a transitive dep of `@zeno/db`), vitest for tests, biome for lint.

**Spec reference:** [[spec-unify-db-as-drizzle]]

- [ ] **Step 3: Write `schema.ts`**

Use the host schema as stylistic reference (`packages/db/src/host/schema.ts`). Patterns:
- TypeScript identifiers in camelCase (`threadId`), SQL column names in snake_case via the column-name argument (`text('thread_id')`).
- Indexes declared in the second argument: `(table) => ({ idxLastUsed: index('idx_sessions_last_used').on(table.lastUsedAt) })`.
- Foreign keys via `references(() => connectors.id, { onDelete: 'cascade' })`.
- Composite primary keys via `primaryKey({ columns: [...] })`.
- Blob columns (for AES IV + ciphertext): `blob('iv', { mode: 'buffer' })`.
- `CHECK` constraints not natively supported by drizzle-kit for SQLite → declare via raw `sql` in the table builder's third arg or accept that they re-encode at generate time; verify against the generated SQL in Task 3.

Example skeleton (sessions table, full table — extend the same pattern to all 17):

```ts
import { sql } from 'drizzle-orm';
import {
  blob,
  index,
  integer,
  primaryKey,
  sqliteTable,
  text,
  uniqueIndex,
} from 'drizzle-orm/sqlite-core';

export const sessions = sqliteTable(
  'sessions',
  {
    threadId: text('thread_id').primaryKey(),
    sessionId: text('session_id').notNull(),
    createdAt: text('created_at').notNull().default(sql`CURRENT_TIMESTAMP`),
    lastUsedAt: text('last_used_at').notNull().default(sql`CURRENT_TIMESTAMP`),
  },
  (table) => ({
    idxLastUsed: index('idx_sessions_last_used').on(table.lastUsedAt),
  }),
);

// ... 16 more tables ...
```

For every table, also declare `Insert` and `Select` type aliases at the bottom of the file:

```ts
export type Session = typeof sessions.$inferSelect;
export type NewSession = typeof sessions.$inferInsert;
```

- [ ] **Step 2: Create `packages/db/src/runtime/db.ts`**

```ts
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { drizzle, type BetterSQLite3Database } from 'drizzle-orm/better-sqlite3';
import type { DB as RawDB } from '../shared/client.js';
import { closeSqlite, openSqlite } from '../shared/client.js';
import { applyMigrations, loadMigrations } from '../shared/migrate.js';
import * as schema from './schema.js';

export type RuntimeDB = BetterSQLite3Database<typeof schema>;

const HERE = dirname(fileURLToPath(import.meta.url));
const MIGRATIONS_DIR = join(HERE, 'migrations');

export interface OpenRuntimeDatabase {
  raw: RawDB;
  drizzle: RuntimeDB;
  close: () => void;
}

export function openRuntimeDatabase(path: string): OpenRuntimeDatabase {
  const raw = openSqlite(path);
  const db = drizzle(raw, { schema });
  return {
    raw,
    drizzle: db,
    close: () => closeSqlite(raw),
  };
}

export function runRuntimeMigrations(raw: RawDB): void {
  applyMigrations(raw, loadMigrations(MIGRATIONS_DIR));
}
```

Notes:
- `runRuntimeMigrations` takes the raw `better-sqlite3` handle (not the drizzle wrapper) because `applyMigrations` operates on `prepare`/`exec`/`transaction`. That matches the host pattern.
- Callers will receive both `raw` and `drizzle` from `openRuntimeDatabase` and pass each to the right helper.

Skeleton:

```ts
import { sql } from 'drizzle-orm';
import { connectors } from './schema.js';
import type { RuntimeDB } from './db.js';

interface SeedConnector {
  id: string;
  slug: string;
  name: string;
  // ... shape derived from agent/connectors-catalog.json + the migration-20 SQL
}

const DEFAULTS: SeedConnector[] = [
  // Replicate exactly the rows that migration 20 inserted, sourced from
  // agent/connectors-catalog.json entries with enabled_by_default:true.
];

export function seedDefaultConnectors(db: RuntimeDB): { seeded: number } {
  let seeded = 0;
  for (const c of DEFAULTS) {
    const result = db
      .insert(connectors)
      .values({
        id: c.id,
        slug: c.slug,
        name: c.name,
        // ... remaining columns
      })
      .onConflictDoNothing({ target: connectors.slug })
      .run();
    seeded += result.changes;
  }
  return { seeded };
}
```

If migration 20's seed touches multiple tables (e.g., `connector_skills` or `connector_tool_permissions` in addition to `connectors`), expand the helper to seed each table conditionally. Read migration 20's exact SQL before finalizing this file.

```ts
describe('runRuntimeMigrations', () => {

        .all() as { name: string }[];

      runRuntimeMigrations(raw);

      runRuntimeMigrations(raw);
      const after = raw.prepare('SELECT COUNT(*) as c FROM schema_migrations').get() as { c: number };
      expect(after.c).toBe(before.c);
    } finally {
      close();
```

```ts
export interface Session {
  threadId: string;
  sessionId: string;
  createdAt: string;
  lastUsedAt: string;
}

export class SessionRepo {
  constructor(private readonly db: RuntimeDB) {}

  upsert(threadId: string, sessionId: string): void {
    this.db
      .insert(sessions)
      .values({ threadId, sessionId })
      .onConflictDoUpdate({
        target: sessions.threadId,
        set: { sessionId, lastUsedAt: sql`CURRENT_TIMESTAMP` },
      })
      .run();
  }

  get(threadId: string): string | null {
    const row = this.db
      .select({ sessionId: sessions.sessionId })
      .from(sessions)
      .where(eq(sessions.threadId, threadId))
      .get();
    return row?.sessionId ?? null;
  }

  delete(threadId: string): void {
    this.db.delete(sessions).where(eq(sessions.threadId, threadId)).run();
  }

  touch(threadId: string): void {
    this.db
      .update(sessions)
      .set({ lastUsedAt: sql`CURRENT_TIMESTAMP` })
      .where(eq(sessions.threadId, threadId))
      .run();
  }

  list(): Session[] {
    return this.db.select().from(sessions).orderBy(desc(sessions.lastUsedAt)).all();
  }

  sparkline(hours = 24): Array<{ hour: string; count: number }> {
    const since = new Date(Date.now() - hours * 3600_000).toISOString();
    const rows = this.db.all<{ hour: string; count: number }>(sql`
      SELECT strftime('%Y-%m-%dT%H:00:00Z', last_used_at) AS hour, COUNT(*) AS count
      FROM ${sessions}
      WHERE last_used_at >= ${since}
      GROUP BY hour
      ORDER BY hour ASC
    `);

    const buckets = new Map(rows.map((r) => [r.hour, r.count]));
    const result: Array<{ hour: string; count: number }> = [];
    const now = new Date();
    for (let i = hours - 1; i >= 0; i--) {
      const d = new Date(now.getTime() - i * 3600_000);
      const key = `${d.toISOString().slice(0, 13)}:00:00Z`;
      result.push({ hour: key, count: buckets.get(key) ?? 0 });
    }
    return result;
  }
}
```

Pattern notes:
- The class name, constructor signature, and method signatures are identical to `packages/storage/src/repos/sessions.ts`. That is the public-API-parity contract.
- Drizzle `eq(col, value)` replaces `WHERE col = ?`.
- `sql\`...\`` template tag handles raw SQL where the query builder doesn't fit (e.g., `strftime`, `GROUP BY hour`).
- `sql\`CURRENT_TIMESTAMP\`` keeps the existing default behavior.
- `Buffer` columns map via `blob({ mode: 'buffer' })` — irrelevant here, applies to encrypted repos in later waves.

```ts
setSecret(connectorId: string, key: string, plaintext: string): void {
  const { iv, ciphertext } = encrypt(this.opts.masterKey, this.opts.profileId, plaintext);
  this.db
    .insert(connectorSecrets)
    .values({ connectorId, key, valueEncrypted: ciphertext, iv })
    .onConflictDoUpdate({
      target: [connectorSecrets.connectorId, connectorSecrets.key],
      set: { valueEncrypted: ciphertext, iv },
    })
    .run();
}

getSecret(connectorId: string, key: string): string | null {
  const row = this.db
    .select()
    .from(connectorSecrets)
    .where(and(eq(connectorSecrets.connectorId, connectorId), eq(connectorSecrets.key, key)))
    .get();
  if (!row) return null;
  return decrypt(this.opts.masterKey, this.opts.profileId, row.iv, row.valueEncrypted);
}
```
