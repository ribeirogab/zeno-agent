Zeno's runtime is Docker-only. The host needs the CLI (`zeno`), Docker, and a recent Node — that's it.

## Prerequisites

- `git`
- `docker` (Engine running; the CLI talks to the Docker socket directly)
- Node.js 24 LTS
- pnpm 10
- macOS or Linux. WSL2 on Windows works; native Windows does not.

## Run the installer

<Callout type="info">
The installer clones the repo to `~/.zeno/zeno-agent/` and symlinks the `zeno` binary into `~/.local/bin/zeno`. The clone path is fixed — there is no `ZENO_HOME` override.
</Callout>

```bash
curl -fsSL https://raw.githubusercontent.com/ribeirogab/zeno-agent/main/install.sh | sh
```

That writes three things:

- `~/.zeno/zeno-agent/` — the cloned repo
- `~/.zeno/state.db` — host-side SQLite holding profile metadata (`chmod 600`, owner-only)
- `~/.local/bin/zeno` — symlink to the built CLI

Make sure `~/.local/bin` is on your `PATH`. Most distros ship that already; if not, add it to your shell rc.

## Verify

```bash
zeno --help
```

If you see the subcommand list, you're done. Next up: [create your first profile](/profile).
